# Final Topic Confirmation

## Selected Track
Wide Project (Application of Big Data Technologies)

## Final Topic
City Mobility Demand Analytics and Monitoring Dashboard (NYC Taxi + Weather)

## Why this topic
- Delivers a full end-to-end pipeline (ingestion -> processing -> storage -> visualization).
- Meets the requirement of using at least three big data technologies.
- Is feasible under a limited budget (< 100 USD) with short-lived cloud resources.
- Supports both batch and near-real-time analytics, which strengthens demonstration quality.

## Required technologies in scope
- Apache Spark (batch + structured streaming)
- Kafka (event/messaging layer)
- BigQuery (analytical warehouse)
- Tableau (dashboard and demo UI)
- GCS (data lake layer)

## Scope boundaries
- Focus on analytics and monitoring, not production-grade 24/7 service.
- Use CPU-first setup; GPU remains optional extension.
- Prioritize reproducible experiments and report-ready outputs.
